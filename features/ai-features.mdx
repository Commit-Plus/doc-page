## Generate a commit message

1. Open the commit bar and choose a provider from the provider menu.
2. Click the **Generate commit message** <Icon icon="sparkles" /> button.
3. Review and edit the generated message before committing.

Commit+ prefers staged changes. If nothing is staged, it generates from tracked changes and untracked files in the working tree instead, so staging is not required just to draft a message.

The result follows the Conventional Commits format, such as `feat:`, `fix:`, `refactor:`, or `docs:`. Commit+ uses the current branch, changed-file metadata, a bounded patch, and recent commit subjects to make the wording specific and consistent with the repository. If files change while generation is in progress, the stale result is rejected instead of replacing the editor contents.

## Configure a cloud provider

Open **Settings → AI Providers**, enter the API key for OpenAI, Claude, or Gemini, then click **Done**. Return to the commit bar and select the configured provider.

API keys are stored only in this Mac's Keychain. You can replace or remove a key from the same settings screen. Commit+ does not provide or bill for cloud-model usage; requests use your provider account and are subject to that provider's pricing and limits.

<Warning>
  Cloud providers receive the repository context needed to generate the message, including changed-file information and a bounded patch. Commit+ sends the request directly to the selected provider API. Review your provider's data and retention policies before using it with sensitive code.
</Warning>

## Use Apple Intelligence on-device

Select **Apple Intelligence — On-device** from the provider menu. No API key is required. The system model must be available on the Mac, Apple Intelligence must be enabled in System Settings, and its model must be ready.

With Apple Intelligence selected, commit context is processed on the Mac and is not uploaded to an AI service.

## Access

AI commit-message generation is a Commit+ Pro feature. Sign in to Commit+ so the app can check your plan before generating a message. Provider selection and API keys remain local to the Mac.
