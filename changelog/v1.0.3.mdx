`v1.0.3` · Released July 23, 2026

## Pull Requests view

Browse open pull requests for a connected repository without leaving Commit+. Each entry shows the PR number and title, source and target branches, author, state, and last updated time.

Use **Open in Browser** to jump to the provider's pull request page. GitHub is supported through a connected provider account. See [Pull Requests](/features/pull-requests).
